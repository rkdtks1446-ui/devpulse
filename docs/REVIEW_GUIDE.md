# DevPulse 구조화 코드 리뷰 가이드

리뷰어는 피드백의 중요도와 반영 필수 여부를 명확히 전달하기 위해 코멘트 서두에 아래 태그를 사용합니다.

| 태그 | 의미 | 병합 조건 | 예시 |
| :--- | :--- | :--- | :--- |
| **`[MUST]`** | 버그, 보안 결함, 예외 누락 등 반드시 수정해야 하는 필수 사항 | 수정 완료 후 병합 가능 | `[MUST] 음수 입력 시 0으로 보정하는 방어 로직을 추가해 주세요.` |
| **`[SHOULD]`** | 가독성, 성능, 유지보수성 향상을 위한 권장 개선 사항 | 가급적 반영하거나 사유 회신 | `[SHOULD] 정규식을 상수로 분리하면 재사용성이 좋아집니다.` |
| **`[NIT]`** | 변수명, 오타, 주석 등 사소한 스타일 제안 | 작성자 선택에 따라 반영 | `[NIT] 주석의 오타를 수정하면 좋겠습니다.` |
